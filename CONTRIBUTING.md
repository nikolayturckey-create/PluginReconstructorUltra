# Contributing

Спасибо за интерес к Plugin Reconstructor Ultra.

## Перед изменениями

- Используйте JDK 21 или новее.
- Не добавляйте в репозиторий чужие плагины/JAR без разрешения правообладателя.
- Не добавляйте функции, предназначенные для обхода лицензий, активаций, внешних ключей или удалённых проверок доступа.

## Сборка

Linux/macOS:

```bash
./scripts/build.sh
```

Windows:

```bat
scripts\build.bat
```

## Pull requests

В PR кратко укажите:

1. Что изменено.
2. Зачем это нужно.
3. Как проверялось.
4. Есть ли изменения в формате выходного проекта.
