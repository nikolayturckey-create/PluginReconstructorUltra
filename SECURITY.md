# Security Policy

Plugin Reconstructor Ultra обрабатывает потенциально недоверенные JAR-файлы. Не запускайте анализируемый код вручную и не отключайте системные средства защиты ради декомпиляции.

## Сообщение об уязвимостях

Если вы нашли проблему, при которой специально подготовленный JAR может выполнить код, записать файлы вне выбранной папки, повредить данные или обойти ограничения инструмента, не публикуйте рабочий exploit в публичном issue. Сначала сообщите владельцу репозитория приватным способом через GitHub.

## Scope

Инструмент предназначен для восстановления собственных проектов, совместимости, обучения и аудита с разрешением владельца. Он не предназначен для обхода лицензирования, активации или контроля доступа.
