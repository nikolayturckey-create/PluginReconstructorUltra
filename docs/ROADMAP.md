# Roadmap

## 0.3 — качество Java

- method-level сравнение результатов разных движков;
- отдельная обработка multi-release вариантов;
- mapping переименованных illegal identifiers;
- проверка source-to-bytecode call graph;
- экспорт CFG для проблемных методов.

## 0.4 — подготовка к сборке

- более точное определение версий Paper/Spigot/NMS;
- fingerprint shaded-библиотек;
- автоматическое создание source map «класс → Java-файл → движок»;
- классификация ожидаемых compiler errors без автоматической сборки.

## 0.5 — читаемость обфускации

- необязательные semantic names для listener/command/service;
- reversible mapping без заявления, что имена оригинальные;
- распознавание команд, событий, scheduler-задач и inventory GUI.

## 1.0

- стабильные обновления движков;
- очередь нескольких разрешённых JAR;
- сравнение двух версий одного проекта;
- plugin SDK для дополнительных анализаторов.
